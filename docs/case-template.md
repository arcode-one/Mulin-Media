# Адаптивный шаблон кейса

Для нового кейса используйте структуру `case.html`, подключение `css/case-detail.css`
и `js/case-detail-main.js`. Сохраняйте класс `case-page` у body и настройки общего
хедера/футера из исходного файла. Меняйте title, метаданные, хлебные крошки,
содержимое статьи и изображения. Это шаблон вёрстки, не автоматическое создание
страниц или интеграция с CMS.

- `.case-detail__article` — единая колонка до 711 px с боковыми отступами 20 px.
- `.case-detail__title` — заголовок; выделение результата через `span`.
  Не добавляйте принудительные переносы для подгонки под конкретную ширину.
- `.case-detail__tags` — любое количество меток: переносятся автоматически.
- `.case-detail__section` — раздел с h2, p, ul; `.case-detail__step` — шаг с h3.
  ID нужны только для ссылок и aria-labelledby, не для адаптивных CSS-правил.
- `.case-detail__figure` — картинка или picture. Указывайте реальные width/height
  изображения и alt. Без модификатора сохраняется исходная пропорция.
  Модификатор `--discount` предназначен только для существующего кадрирования
  баннера логистического кейса; новым произвольным изображениям он не нужен.
- `.case-metrics` — dl с div > dt + dd. Можно менять число показателей и длину
  подписей. На телефонах показатели располагаются в три колонки без мелкого
  шестиколоночного текста и горизонтального скролла страницы.
- `.case-detail__cta` — завершающий призыв к действию.

Контент всегда находится в нормальном потоке. Не задавайте высоту текстовым
блокам, фиксированную ширину отдельным абзацам и CSS по ID конкретного кейса.

Проверка: 1440, 1200, 1024, 992, 820, 768, 640, 576, 430, 390, 360 px;
также 1366, 1100, 1000, 900, 800, 760, 700, 650, 600, 500, 414, 375 px.
Проверьте длинный заголовок, дополнительные метки, длинные списки, разные
пропорции изображений и другое количество показателей.

Регрессионная проверка: запустите локальный сервер, затем
`node scripts/check-case-responsive.cjs` (нужны Playwright и Chrome).
Через `CASE_URL` можно передать URL нового кейса; `PLAYWRIGHT_MODULE` позволяет
указать путь к Playwright, если он установлен вне проекта. Проверяются 33 ширины
и два варианта: исходный и с длинным тестовым контентом (изменяется только DOM
в тестовом браузере, файлы страницы не меняются).
